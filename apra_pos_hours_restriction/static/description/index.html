POS Opening Hours Restriction


Control your POS operating hours by restricting session opening and closing times. Ensure cashiers can only open or close POS sessions during defined business hours, reducing errors and improving operational discipline.

- Please make sure first the configuration timezone in user that already correct.

- This is optional, you can fill in one or both of them.


- Will display a warning popup if you open the session before the configuration opening time.


- Will display a warning popup if you close the session before the configuration closing time.


- Will automatically display a warning popup if still in POS after the configuration closing time, to force you to popup cash control for close POS and cannot be discarded or canceled on this action.
